# GeoDep

IFE-CEPII project on bilateral trade dependencies (BACI, HS 2022).

- `geodep_shiny/`: the GeoDep trade dependency explorer (R Shiny app). Open `geodep_shiny/geodep_shiny.Rproj`, or set that folder as the working directory, before running `master.R`. See `geodep_shiny/README.md` and `geodep_shiny/CLAUDE.md`.
- `DT_2026/`: GeoDep working paper (2026).

Raw data and `.Renviron` (with `DROPBOX_DIR`) are not on GitHub; each user needs their own copy.
